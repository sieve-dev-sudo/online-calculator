## ✨ Features

- **គណនាធម្មតា**: បូក ដក គុណ ចែក ភាគរយ (%) វង់ក្រចក ( ) និងចំណុចទសភាគ
- **Scientific**: sin, cos, tan, lg, ln, √x, xʸ, x!, 1/x, π និង e
- **ប៊ូតុង 2nd**: ប្តូរទៅ sin⁻¹, cos⁻¹, tan⁻¹, 10ˣ, eˣ និង x² ភ្លាមៗ
- **DEG / RAD**: ជ្រើសរើសរបៀបគណនាមុំ មានស្លាកបង្ហាញលើអេក្រង់
- **Live Preview**: បង្ហាញលទ្ធផលបណ្តោះអាសន្នពេលកំពុងវាយ ហើយបង្ហាញកន្សោមចាស់ក្រោយចុច =
- **Dark Mode**: ប្តូរពន្លឺ / ងងឹត ដោយចុចប៊ូតុង 🌙 / ☀️
- **Keyboard**: វាយលេខ និងសញ្ញាពី Keyboard បាន ទាំងភាសា **ខ្មែរ** និង **English** រួមទាំង Numpad
- **Responsive**: លើ Laptop មាន ៧ ជួរឈរ លើទូរស័ព្ទបង្ហាញពេញអេក្រង់ ហើយប្តូរបានរវាង **Basic** និង **Scientific** mode
- **សុវត្ថិភាព**: គណនាដោយ Parser ផ្ទាល់ខ្លួន មិនប្រើ `eval()` ឬ `Function()`
- **ចាំការកំណត់**: Theme, DEG / RAD និង Keypad mode ត្រូវបានរក្សាទុកក្នុង Browser (`localStorage`)

## ⌨️ Keyboard Shortcuts

| គ្រាប់ចុច | មុខងារ |
|---|---|
| `0` ដល់ `9` | វាយលេខ |
| `+` `-` `*` `/` | បូក ដក គុណ ចែក |
| `^` | ស្វ័យគុណ (xʸ) |
| `(` `)` | វង់ក្រចក |
| `%` | ភាគរយ |
| `!` | Factorial (x!) |
| `.` | ចំណុចទសភាគ |
| `Enter` ឬ `=` | គណនា |
| `Backspace` | លុបម្តងមួយតួ |
| `Esc` ឬ `Delete` | លុបទាំងអស់ (AC) |

## 📱 Mobile Mode

- **Basic**: ៤ ជួរឈរ ប៊ូតុងធំៗ សម្រាប់គណនាធម្មតា
- **Scientific**: ៥ ជួរឈរ មានមុខងារវិទ្យាសាស្ត្រពេញលេញ
- ចុចប៊ូតុង **ការ៉េពីរជាន់ពណ៌ទឹកក្រូច** នៅជ្រុងក្រោមខាងឆ្វេង ដើម្បីប្តូររវាង Basic និង Scientific

## 🚀 How to Run

1. Clone ឬ Download Repository:

   ```bash
   git clone <repo-url>
   ```

2. បើកឯកសារ `index.html` ដោយ Browser ណាមួយ (Chrome, Firefox...)
3. សាកល្បងគណនា ប្តូរ Dark Mode ប្តូរ DEG / RAD ហើយបើកលើទូរស័ព្ទដើម្បីមើល Mobile Mode។
